## Problem

The Ground Control chat (ConversationScreen) is hard to use: agent messages are
low-contrast and hard to read; messages arrive in markdown but render as raw text;
the thread force-scrolls to the bottom whenever the keyboard is open, so you can't
scroll up while typing; a "Make this a spec" action clutters the bar and is
confusing under the new WorkItem flow; and the compose bar feels unlike a modern
messaging app.

## User story

As an operator chatting with agents from my phone, I want a legible, markdown-aware,
messaging-app-like chat, so that I can read agent output and reply comfortably.

## Approach

Scoped, operator-approved (MOS-212), all in `ui/messages/ConversationScreen.kt`:

1. **Contrast** — agent bubbles switch from `surfaceVariant`/`onSurfaceVariant` to a
   higher-contrast `surfaceContainerHigh` + `onSurface`.
2. **Markdown** — agent messages render via the existing `mikepenz` M3 markdown
   renderer (already shipped for spec bodies), colored `onSurface`; human bubbles
   remain plain `Text` (short replies; markdown fights the `onPrimary` bubble color).
3. **Scroll-while-typing** — derive `isAtBottom` from the list state; auto-scroll to
   the newest item only when already at the bottom, and drop the keyboard-open
   force-scroll so focusing the input no longer yanks the thread down.
4. **Remove "Make this a spec"** — delete the `NoteAdd` top-bar action and the
   now-unused `requestSpec()` VM method.
5. **Compose bar** — rounded pill `OutlinedTextField` + filled circular
   `FilledIconButton` send, with the row laid out to leave a leading slot for a
   future attach/file button (not built now).

Verification: `mship build` (compile/assemble); Compose visuals can't be
emulator-verified in this environment.
